# Abyss Guides

Abyss Guides is an independent guide site for deep-sea survival and exploration games, starting with Subnautica 2 Early Access.

Canonical URL:

https://www.abyssguides.com

## Local Development

```bash
pnpm install
pnpm dev
```

## Production Build

```bash
pnpm build
```

## Notes

- This project was copied from the existing MkSaaS/ThumbAI codebase as a separate project.
- ThumbAI remains in its original repository.
- Abyss Guides should use `https://www.abyssguides.com` as the canonical base URL.
- The site is an independent fan-made guide site and is not affiliated with Unknown Worlds Entertainment, Krafton, or the official Subnautica 2 team.
